# 데이터 표준 — `data/contests/<id>.json`

## 1. 필드

| 키 | 필수 | 뜻 |
|---|---|---|
| `name` | ○ | 공식 명칭(한국어 우선, 해외 대회는 영문) |
| `organizer` | ○ | 주최·주관 |
| `type` | ○ | `논문상` `학생논문경진` `AI·데이터 챌린지` `설계·개발 경진` `아이디어·특허 공모` `펠로우십·장학` `문학·수기` `영상·사진` `디자인·미술` `창업·사업화` `과학·탐구 대회` 중 하나 |
| `fields` | ○ | `전자파·RF` `반도체·회로` `통신·네트워크` `AI·데이터` `전기·전력` `컴퓨터·SW` `과학기술 전반` `국방` `문화·예술` `사회·정책` `환경` `관광·지역` `복지·건강` `경제·금융` `교육` 중 여럿 |
| `summary` | ○ | 무엇을 내고 어떻게 심사하는지 1~2문장. 추상어 대신 제출물과 심사 단계를 쓴다 |
| `eligibility` | | 공고의 참가 자격 한 줄(화면에 그대로 나간다) |
| `gradOk` | | 대학원생이 참가할 수 있으면 true |
| `prize` | | 상금·혜택 한 줄 |
| `cycle` | ○ | `연 1회` `연 2회` `상시` `비정기` |
| `typicalDeadline` | | 보통 마감 시기 설명 |
| `typicalMonths` | | 보통 마감하는 달(1~12) 배열. 공고 전 회차의 예상 월과 12개월 표에 쓴다 |
| `nextDeadline` | | 공고된 마감일 `YYYY-MM-DD`. 지난 날짜면 '이번 회차 마감'으로 보이고 다음 해 예상으로 넘어간다 |
| `nextDeadlineNote` | | 다음 회차 일정 설명. 추정이면 '전년도 기준 추정' |
| `status` | ○ | `모집중` `모집예정` `다음 회차 대기` `확인필요` |
| `url` | △ | 공식 페이지. `url`과 `sourceUrl` 중 하나는 필수 |
| `sourceUrl` | △ | 날짜·상금의 근거로 삼은 페이지 |
| `confidence` | | `high` `medium` `low`. 화면에는 나가지 않는다 |
| `verifiedAt` | ○ | 마지막으로 확인한 날 `YYYY-MM-DD`. sitemap `lastmod`, JSON-LD `dateModified`에 쓴다 |
| `createdAt` | | 처음 넣은 시각 |
| `elig` | ○ | 자격 판별 규칙(2절) |

## 2. `elig` — 자격 판별 규칙

`assets/eligibility.js`의 `judge(contest, profile)`가 읽는다. 결과는 `가능`(조건을 모두 채움), `조건부`(사이트가 확인할 수 없는 조건이 있거나 정보가 더 필요함), `불가`(맞지 않는 조건이 있음) 셋이다.

| 키 | 예 | 판별 |
|---|---|---|
| `who` | `["학부","석사","박사"]` | 참가할 수 있는 신분: `초등` `중등` `고등` `학부` `석사` `박사` `박사후` `일반`(학생이 아닌 성인: 취준생·직장인·자영업·은퇴). `일반`이 있으면 학적 조건을 보지 않는다. 석박통합은 석사·박사 둘 다로 본다 |
| `status` | `["재학","휴학"]` | 학생일 때 허용하는 학적. 졸업예정은 재학으로 본다. 휴학이 빠져 있으면 조건부, 입학예정이 빠져 있으면 불가 |
| `fullTime` | `true` | 비전일제 학생은 불가 |
| `uni` | `"국내"` | 해외 대학 소속은 불가(대학생·대학원생에게만 적용) |
| `regions` | `["광주","전남","전북"]` | 대학 소재지(대학생·대학원생에게만 적용). 소재지를 안 넣으면 조건부 |
| `residence` | `["서울"]` | 거주 시·도. 거주 지역을 안 넣으면 조건부 |
| `nationality` | `"KR"` / `"KR_IF_ABROAD"` | 대한민국 국적만 / 해외 대학 재학생만 한국 국적 필요 |
| `foreignNote` | 문장 | 외국 국적이면 조건부로 보여 줄 문장 |
| `age` | `{"min":19,"max":29,"ref":"2027-09-01","soft":true,"note":"…"}` | 만 나이. 기준일은 `ref` → 남아 있는 `nextDeadline` → 보통 마감하는 달의 다음 차례 말일 → 오늘 순. 생년월일이 없으면 조건부, `soft`면 묻지 않는다(대상 신분이면 거의 채우는 하한) |
| `unemployed` | `true` | 재직 중이면 불가 |
| `generalUnemployed` | `true` | 학생이 아닌데 재직 중이면 불가 |
| `employed` | 문장 | 재직 중이면 이 문장으로 불가 |
| `fieldReq` | `["공학","자연과학"]` | 전공 계열 |
| `newStudent` | `{"ref":"2027-02-01","maxMonths":12}` | 입학 연월부터 기준일까지 개월 수. 입학 연월이 없으면 조건부 |
| `members` | `["대한전자공학회"]` | 필요한 학회 회원. 없으면 조건부('가입하면 참가 가능') |
| `limitedFor` | `{"일반":"…"}` | 대학생·대학원생이 아닌 사람(박사후 포함)에게 조건부로 보여 줄 문장 |
| `manual` | `["대학 추천 필요"]` | 사이트가 판별할 수 없는 조건. 항상 조건부 |
| `unknown` | 문장 | 참가 자격을 확인하지 못했을 때. 항상 조건부 |
| `needs` | `["학생 제1저자 논문"]` | 준비물. 판별에는 쓰지 않고 '준비할 것'에 보인다 |

프로필 필드: `role`(초등학생·중학생·고등학생·대학생·대학원생·취업준비생·직장인·자영업·프리랜서·은퇴·무직), `birth`(YYYY-MM-DD), `residence`(시·도), `nationality`(KR·other), `memberships`. 대학생·대학원생만: `gradLevel`(석사·박사·석박통합·박사후), `status`(재학·휴학·입학예정·졸업예정), `fullTime`, `university`, `uniCountry`(국내·해외), `uniRegion`, `field`(공학·자연과학·기타), `entry`(YYYY-MM), `employed`. 직장인·자영업·박사후는 재직으로 본다. 예전 `level` 기반 프로필은 `normalize()`가 바꿔 읽는다.
